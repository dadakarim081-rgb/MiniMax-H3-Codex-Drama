## Root cause carried from CD1

The old `comfyui-mcp@0.49.3` generic UI conversion was not used as execution
truth. CD1 found that it silently dropped the H3 storyboard Autogrow child and
`ComfyMathExpression.values.a`, and read the original node 39 positional
widgets against a newer schema. The latter produced incorrect
`enable_chunking`, `device`, and `precision` values.

The pinned MCP was upgraded only in `.mcp.json` to `comfyui-mcp@0.49.6`.
The 0.49.6 package was inspected in a temporary directory, not vendored. Its
Autogrow repair corresponds to [issue #762](https://github.com/artokun/comfyui-mcp/issues/762)
and [PR #763](https://github.com/artokun/comfyui-mcp/pull/763); the 0.49.6
release includes that fix as recorded in [release PR #849](https://github.com/artokun/comfyui-mcp/pull/849).

## Route and mutable fields

The manifest adds one route under `modes.r2v.variants`:

```text
--mode r2v --variant storyboard-original
```

The preparer verifies the pinned API SHA before patching. It accepts only:

| Request field | API location | Behavior |
|---|---|---|
| finished prompt | node 2 `value` | preserves the node 2 → node 11 prompt link |
| storyboard image | node 9 `image` | preserves node 9 → node 11 `ref_images.ref_image_0` |
| standalone Audio1 | new node 43 `LoadAudio.audio` → node 11 `ref_audios.ref_audio_0` | at most one; never writes `ref_video_audios` |
| seed | node 31 `noise_seed` | validates non-negative integer |
| output prefix | node 42 `filename_prefix` | patches only the final writer |

Duration is frozen and rejected, as are size, model, sampler, scheduler,
step, denoise, frame, video, and reference-size overrides. The optional
Audio1 node is added only when a standalone audio filename is supplied; the
baseline asset does not invent one. External `h3-storyboard` and Prompt
Composer remain outside this route. A finished Prompt Composer string is
passed unchanged with `prompt_enhance=false`.

The Producer architecture did not need a new orchestration layer. Its
existing route/workflow bookkeeping accepts the explicit route, and its
preflight file report now includes the pinned API asset. The H3 ComfyUI skill
and runtime reference document the new selector and its frozen-field policy.
